# 🎨 Redesign de Interfaces — WhatsApp e YouTube

## 📌 Sobre o projeto

Este projeto foi desenvolvido como atividade acadêmica do curso de Sistemas de Informação, com o objetivo de propor uma reformulação visual das interfaces do WhatsApp e YouTube.

A proposta busca explorar alternativas de design, organização dos elementos visuais e experiência do usuário.

## 🎯 Objetivo

Aplicar conhecimentos de design de interfaces por meio da criação de protótipos, desenvolvendo uma visão mais crítica sobre a apresentação e a organização de plataformas digitais.

## 🛠️ Ferramenta utilizada

- Canva — Criação e prototipagem das interfaces.

## 📱 Interfaces trabalhadas

**WhatsApp:** proposta de reformulação visual da interface do aplicativo.

**YouTube:** proposta de reformulação visual da interface da plataforma.
